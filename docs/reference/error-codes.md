# Error Codes Directory

Centralized directory of error codes and client hints returned by MBKAuthe v6.

---

## Error Response Structure

```json
{
  "success": false,
  "statusCode": 401,
  "errorCode": 601,
  "error": {
    "code": 601,
    "message": "The username or password you entered is incorrect. Please try again.",
    "details": "Check your spelling and make sure Caps Lock is off"
  },
  "message": "The username or password you entered is incorrect. Please try again.",
  "hint": "Check your spelling and make sure Caps Lock is off",
  "timestamp": "2026-09-14T06:00:00.000Z"
}
```

---

## 1. Authentication Errors (600–699)

| Code | Identifier | Message | Recovery Hint |
|---|---|---|---|
| `601` | `INVALID_CREDENTIALS` | Invalid username or password | Check spelling and verify Caps Lock is off. |
| `602` | `USER_NOT_FOUND` | User account not found | Check the username and try again. |
| `603` | `INCORRECT_PASSWORD` | Incorrect password | Ensure correct password for this account. |
| `604` | `ACCOUNT_INACTIVE` | Account is inactive | Contact administrator to reactivate account. |
| `605` | `APP_NOT_AUTHORIZED` | Not authorized for this application | Account is not authorized for the requested application. |

---

## 2. Two-Factor Authentication (700–799)

| Code | Identifier | Message | Recovery Hint |
|---|---|---|---|
| `701` | `TWO_FA_REQUIRED` | Two-factor authentication required | Enter the 6-digit authentication code from your authenticator app. |
| `702` | `TWO_FA_INVALID_TOKEN` | Invalid 2FA code | Use the latest code generated by your app. |
| `703` | `TWO_FA_NOT_CONFIGURED` | 2FA not configured | Contact administrator to set up 2FA. |
| `704` | `TWO_FA_EXPIRED` | 2FA code expired | Code has expired; enter a fresh 6-digit code. |

---

## 3. Session Errors (800–899)

| Code | Identifier | Message | Recovery Hint |
|---|---|---|---|
| `801` | `SESSION_EXPIRED` | Session expired | Session has expired due to inactivity; please log in again. |
| `802` | `SESSION_INVALID` | Invalid session | Session is no longer valid (may have been evicted by max session limit). |
| `803` | `SESSION_NOT_FOUND` | Session not found | Log in to access this resource. |

---

## 4. Authorization & Permissions (900–999)

| Code | Identifier | Message | Recovery Hint |
|---|---|---|---|
| `901` | `INSUFFICIENT_PERMISSIONS` | Insufficient permissions | Account does not hold the required `app:service:action` permission. |
| `902` | `ROLE_NOT_ALLOWED` | Role not allowed | Feature requires a higher or different role level. |

---

## 5. Tokens & Validation (1000–1099)

| Code | Identifier | Message | Recovery Hint |
|---|---|---|---|
| `1001` | `MISSING_REQUIRED_FIELD` | Required field missing | Fill in all mandatory request parameters. |
| `1002` | `INVALID_USERNAME_FORMAT` | Invalid username format | Username must be 1–255 characters. |
| `1003` | `INVALID_PASSWORD_LENGTH` | Invalid password length | Password must be at least 8 characters. |
| `1004` | `INVALID_TOKEN_FORMAT` | Invalid token format | Check token format (e.g. 6-digit code). |
| `1005` | `INVALID_AUTH_TOKEN` | Invalid API token | The provided Bearer token is invalid. |
| `1006` | `API_TOKEN_EXPIRED` | API token expired | The provided API token has passed its expiration date. |
| `1007` | `TOKEN_SCOPE_INSUFFICIENT` | Token scope insufficient | API token lacks the required permission scope for this operation. |

---

## 6. Rate Limiting & Server (1100–1299)

| Code | Identifier | Message | Recovery Hint |
|---|---|---|---|
| `1101` | `RATE_LIMIT_EXCEEDED` | Too many requests | Wait a few minutes before trying again. |
| `1201` | `INTERNAL_SERVER_ERROR` | Internal server error | An unexpected server error occurred; try again later. |
| `1202` | `DATABASE_ERROR` | Database error | Temporary database connection issue; automatic retry in progress. |
| `1203` | `CONFIGURATION_ERROR` | Configuration error | Service configuration error; contact administrator. |

---

## 7. OAuth Errors (1300–1399)

| Code | Identifier | Message | Recovery Hint |
|---|---|---|---|
| `1301` | `GITHUB_NOT_LINKED` | GitHub account not linked | Link your GitHub account in profile settings. |
| `1302` | `GITHUB_AUTH_FAILED` | GitHub authentication failed | Re-try GitHub login or use username/password. |
| `1303` | `OAUTH_STATE_MISMATCH` | OAuth state mismatch | Security verification failed; restart login flow. |
