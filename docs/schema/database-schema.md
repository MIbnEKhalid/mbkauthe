# Database Schema & DDL Reference

MBKAuthe v6 maintains an optimized relational data model with complete parity across **PostgreSQL** and **SQLite**. All tables use the `mbkcore_` prefix for namespace isolation.

---

## Entity Relational Tables

### 1. `mbkcore_roles`
Role definitions and administrative flags.
- `id` (INTEGER GENERATED BY DEFAULT AS IDENTITY / INTEGER PRIMARY KEY AUTOINCREMENT)
- `name` (VARCHAR(50) UNIQUE NOT NULL) — Role identifier (e.g., `superadmin`, `admin`, `author`, `normaluser`)
- `label` (TEXT) — Human-readable display label
- `description` (TEXT) — Role access summary
- `is_system` (BOOLEAN DEFAULT false / INTEGER DEFAULT 0) — Protected system role flag
- `created_at` (TIMESTAMP WITH TIME ZONE DEFAULT now() / TEXT DEFAULT CURRENT_TIMESTAMP)
- `updated_at` (TIMESTAMP WITH TIME ZONE DEFAULT now() / TEXT DEFAULT CURRENT_TIMESTAMP)

### 2. `mbkcore_users`
Core user credentials, profiles, and application permissions.
- `id` (INTEGER GENERATED ALWAYS AS IDENTITY / INTEGER PRIMARY KEY AUTOINCREMENT)
- `username` (VARCHAR(50) UNIQUE NOT NULL) — Primary identity key referenced across the system
- `password` (TEXT DEFAULT '12345670') — Legacy password compatibility field
- `password_hash` (VARCHAR(255)) — Scrypt or PBKDF2 hashed password
- `is_active` (BOOLEAN DEFAULT false / INTEGER DEFAULT 0) — Account activation state
- `is_local_only` (BOOLEAN DEFAULT false / INTEGER DEFAULT 0) — Local-only development user guard (restricted from production)
- `role` (VARCHAR(50) DEFAULT 'normaluser' REFERENCES mbkcore_roles(name))
- `have_mail_account` (BOOLEAN DEFAULT false / INTEGER DEFAULT 0)
- `allowed_apps` (JSONB / TEXT DEFAULT '["Portal", "mbkauthe"]') — Permitted ecosystem apps
- `full_name` (VARCHAR(100))
- `user_id` (VARCHAR(9) UNIQUE) — 9-digit alphanumeric member identifier
- `email` (TEXT DEFAULT 'support@mbktech.org')
- `image` (TEXT DEFAULT 'https://portal.mbktech.org/icon.svg')
- `bio` (TEXT DEFAULT 'I am ....')
- `social_accounts` (TEXT DEFAULT '{}')
- `positions` (JSONB / TEXT DEFAULT '{"Not_Permanent": "Member Is Not Permanent"}')
- `perm_version` (INTEGER DEFAULT 1) — Cache busting version for permissions
- `last_login` (TIMESTAMP WITH TIME ZONE / TEXT)
- `created_at` (TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP / TEXT DEFAULT CURRENT_TIMESTAMP)
- `updated_at` (TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP / TEXT DEFAULT CURRENT_TIMESTAMP)

### 3. `mbkcore_session` (Unified Session Store)
High-performance consolidated session store replacing redundant multi-table session schemas.
- `sid` (VARCHAR DEFAULT gen_random_uuid()::text PRIMARY KEY / TEXT PRIMARY KEY) — Session identifier cookie value
- `id` (TEXT GENERATED ALWAYS AS (sid) STORED / VIRTUAL) — Virtual alias for query compatibility
- `sess` (JSONB DEFAULT '{}'::jsonb NOT NULL / TEXT DEFAULT '{}' NOT NULL) — Session state payload
- `expire` (TIMESTAMP WITH TIME ZONE / TEXT) — Expiration timestamp
- `username` (VARCHAR(50) REFERENCES mbkcore_users(username) ON DELETE CASCADE) — User association
- `created_at` (TIMESTAMP WITH TIME ZONE DEFAULT now() / TEXT DEFAULT CURRENT_TIMESTAMP)
- `last_activity` (TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP / TEXT DEFAULT CURRENT_TIMESTAMP)
- `meta` (JSONB / TEXT) — Device metadata, IP address, and client user-agent details

Indexes:
- `idx_mbkcore_session_expire` ON `(expire)`
- `idx_mbkcore_session_last_activity` ON `(last_activity)`
- `idx_mbkcore_session_username` ON `(username)`

### 4. `mbkcore_two_factor`
Dedicated RFC 6238 TOTP two-factor authentication configuration.
- `username` (VARCHAR(50) PRIMARY KEY REFERENCES mbkcore_users(username) ON DELETE CASCADE)
- `is_enabled` (BOOLEAN DEFAULT false NOT NULL / INTEGER DEFAULT 0 NOT NULL)
- `two_fa_secret` (TEXT) — Encrypted base32 TOTP secret

Index:
- `idx_mbkcore_two_factor_username_status` ON `(username, is_enabled)`

### 5. `mbkcore_passkeys`
WebAuthn / FIDO2 Passkey credentials and anti-replay counters.
- `id` (INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY / INTEGER PRIMARY KEY AUTOINCREMENT)
- `username` (VARCHAR(50) NOT NULL REFERENCES mbkcore_users(username) ON DELETE CASCADE)
- `credential_id` (VARCHAR(255) UNIQUE NOT NULL / TEXT UNIQUE NOT NULL)
- `public_key` (TEXT NOT NULL) — PEM/COSE encoded public key
- `counter` (BIGINT DEFAULT 0 NOT NULL / INTEGER DEFAULT 0 NOT NULL) — Signature counter
- `device_type` (VARCHAR(32) DEFAULT 'single_device' NOT NULL)
- `backed_up` (BOOLEAN DEFAULT false NOT NULL / INTEGER DEFAULT 0 NOT NULL)
- `transports` (TEXT DEFAULT '[]')
- `name` (VARCHAR(255) DEFAULT 'Passkey' NOT NULL)
- `aaguid` (VARCHAR(36))
- `created_at` (TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP / TEXT DEFAULT CURRENT_TIMESTAMP)
- `last_used_at` (TIMESTAMP WITH TIME ZONE / TEXT)

Indexes:
- `idx_mbkcore_passkeys_username` ON `(username)`
- `idx_mbkcore_passkeys_credential_id` ON `(credential_id)`

### 6. `mbkcore_api_tokens`
Hashed Personal Access Tokens (PAT) with granular permissions.
- `id` (INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY / INTEGER PRIMARY KEY AUTOINCREMENT)
- `username` (VARCHAR(50) NOT NULL REFERENCES mbkcore_users(username) ON DELETE CASCADE)
- `name` (VARCHAR(255) NOT NULL) — Token label
- `token_hash` (VARCHAR(128) UNIQUE NOT NULL) — Constant-time SHA-256 hash
- `prefix` (VARCHAR(32) NOT NULL) — Display prefix (e.g., `mbk_pat_`)
- `permissions` (JSONB DEFAULT '{"permissions": []}' NOT NULL / TEXT NOT NULL)
- `last_used` (TIMESTAMP WITH TIME ZONE / TEXT)
- `expires_at` (TIMESTAMP WITH TIME ZONE / TEXT)
- `created_at` (TIMESTAMP WITH TIME ZONE DEFAULT now() / TEXT DEFAULT CURRENT_TIMESTAMP)

### 7. `mbkcore_api_token_profiles`
Reusable permission profile presets for token provisioning.
- `id` (INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY / INTEGER PRIMARY KEY AUTOINCREMENT)
- `name` (VARCHAR(100) UNIQUE NOT NULL)
- `description` (TEXT)
- `permissions` (JSONB / TEXT)
- `profile_key` (VARCHAR(32) UNIQUE)
- `expires_in_days` (INTEGER)
- `is_active` (BOOLEAN DEFAULT true NOT NULL / INTEGER DEFAULT 1 NOT NULL)
- `created_at` (TIMESTAMP WITH TIME ZONE DEFAULT now() / TEXT DEFAULT CURRENT_TIMESTAMP)
- `updated_at` (TIMESTAMP WITH TIME ZONE DEFAULT now() / TEXT DEFAULT CURRENT_TIMESTAMP)

### 8. `mbkcore_cli_auth_sessions`
RFC 8628 OAuth 2.0 Device Authorization Grant sessions.
- `id` (INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY / INTEGER PRIMARY KEY AUTOINCREMENT)
- `device_code_hash` (VARCHAR(64) UNIQUE NOT NULL)
- `user_code_hash` (VARCHAR(64) UNIQUE NOT NULL)
- `client_name` (VARCHAR(255) NOT NULL)
- `profile_id` (INTEGER NOT NULL)
- `username` (VARCHAR(50))
- `token_id` (INTEGER)
- `pending_token` (TEXT)
- `status` (VARCHAR(20) DEFAULT 'pending' NOT NULL) — `pending`, `approved`, `completed`, `denied`, `expired`
- `expires_at` (TIMESTAMP WITH TIME ZONE NOT NULL / TEXT NOT NULL)
- `created_at` (TIMESTAMP WITH TIME ZONE DEFAULT now() / TEXT DEFAULT CURRENT_TIMESTAMP)
- `approved_at` (TIMESTAMP WITH TIME ZONE / TEXT)

### 9. `mbkcore_password_resets`
One-time password reset tokens and attempt counters.
- `id` (INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY / INTEGER PRIMARY KEY AUTOINCREMENT)
- `username` (VARCHAR(50) NOT NULL REFERENCES mbkcore_users(username) ON DELETE CASCADE)
- `reset_token` (TEXT)
- `reset_token_expires` (TIMESTAMP WITH TIME ZONE / TEXT)
- `reset_attempts` (INTEGER DEFAULT 0)
- `last_reset_attempt` (TIMESTAMP WITH TIME ZONE / TEXT)
- `created_at` (TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP / TEXT DEFAULT CURRENT_TIMESTAMP)

### 10. `mbkcore_permission_catalog`
Dynamic `app:service:action` declarative permissions catalog.
- `id` (INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY / INTEGER PRIMARY KEY AUTOINCREMENT)
- `app_key` (VARCHAR(50) NOT NULL)
- `service_key` (VARCHAR(50) NOT NULL)
- `action_key` (VARCHAR(50) NOT NULL)
- `label` (TEXT)
- `is_active` (BOOLEAN DEFAULT true NOT NULL / INTEGER DEFAULT 1 NOT NULL)
- `created_at` (TIMESTAMP WITH TIME ZONE DEFAULT now() / TEXT DEFAULT CURRENT_TIMESTAMP)
- `updated_at` (TIMESTAMP WITH TIME ZONE DEFAULT now() / TEXT DEFAULT CURRENT_TIMESTAMP)
- Unique constraint: `(app_key, service_key, action_key)`

### 11. `mbkcore_role_permissions`
Mapping between role names and cataloged permissions.
- `id` (INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY / INTEGER PRIMARY KEY AUTOINCREMENT)
- `role_name` (VARCHAR(50) NOT NULL REFERENCES mbkcore_roles(name) ON DELETE CASCADE ON UPDATE CASCADE)
- `permission` (VARCHAR(150) NOT NULL)
- `created_at` (TIMESTAMP WITH TIME ZONE DEFAULT now() / TEXT DEFAULT CURRENT_TIMESTAMP)
- Unique constraint: `(role_name, permission)`

### 12. `mbkcore_user_permission_overrides`
Per-user explicit allow/deny permission overrides.
- `id` (INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY / INTEGER PRIMARY KEY AUTOINCREMENT)
- `username` (VARCHAR(50) NOT NULL REFERENCES mbkcore_users(username) ON DELETE CASCADE)
- `permission` (VARCHAR(150) NOT NULL)
- `effect` (VARCHAR(5) NOT NULL) — `allow` or `deny`
- `granted_by` (VARCHAR(50))
- `created_at` (TIMESTAMP WITH TIME ZONE DEFAULT now() / TEXT DEFAULT CURRENT_TIMESTAMP)
- Unique constraint: `(username, permission)`

### 13. `mbkcore_oauth_accounts`
Linked third-party OAuth and OIDC provider identities.
- `id` (INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY / INTEGER PRIMARY KEY AUTOINCREMENT)
- `user_id` (VARCHAR(50) NOT NULL REFERENCES mbkcore_users(username) ON DELETE CASCADE)
- `provider_id` (VARCHAR(50) NOT NULL) — e.g. `google`, `github`, `microsoft`, `discord`, `apple`
- `provider_user_id` (VARCHAR(255) NOT NULL)
- `profile` (JSONB DEFAULT '{}' / TEXT DEFAULT '{}')
- `access_token` (TEXT) — Encrypted token
- `refresh_token` (TEXT) — Encrypted token
- `id_token` (TEXT)
- `token_expires_at` (TIMESTAMP WITH TIME ZONE / TEXT)
- `scope` (TEXT)
- `created_at` (TIMESTAMP WITH TIME ZONE DEFAULT now() / TEXT DEFAULT CURRENT_TIMESTAMP)
- `updated_at` (TIMESTAMP WITH TIME ZONE DEFAULT now() / TEXT DEFAULT CURRENT_TIMESTAMP)
- Unique constraints: `(provider_id, provider_user_id)` and `(user_id, provider_id)`
